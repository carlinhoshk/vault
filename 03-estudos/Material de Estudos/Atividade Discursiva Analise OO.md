### Irei usar de exemplo o Diagrama de caso de usos que criei quando fiz meu projeto integrado 
![[../../__data__/Media/Pasted image 20250602161831.png]]

- *Ator* no caso é o Usuário e ele pode ser tanto um aluno quanto professor, o *Ator* é a entidade que irá realizar operações em nosso software.
- *Cenário* no meu projeto estão representado em varias ações que o Ator pode realizar como se cadastrar, mostrar a pontuação existente ou atribuir pontos a outro usuário.
- *Relacionamento* no meu projeto possui 2 um aonde é usado o <#include> aonde para poder acessar e exibir os dados de algum usuário você precisa está autenticado, em outro exemplo o Usuário professor envia o relatório aonde o uso de <#extend> é relacionado pois quando o relatório é enviado os pontos são enviados juntos.
