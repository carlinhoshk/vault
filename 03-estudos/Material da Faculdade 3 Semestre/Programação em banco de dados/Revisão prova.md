## Introdução - Programação em Banco de Dados

### Controle de Concorrência: 
Como o banco de dados gerencia múltiplos usuários acessando ou alterando os mesmos dados ao mesmo tempo, garantindo consistência.

### SQL (Structured Query Language): 
A linguagem usada para consultar e manipular dados em bancos de dados, permitindo criar, ler, atualizar e excluir informações.

### Transações: 
Como agrupar operações em blocos, garantindo que tudo aconteça ou nada aconteça, para manter a integridade dos dados.
