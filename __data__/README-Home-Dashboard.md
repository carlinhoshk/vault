# 🏠 Home Dashboard - Guia Completo

## 🎯 **O que foi criado:**

### **1. Home Dashboard (`00-index/Home.md`)**
- **Frase motivacional** - Muda a cada atualização
- **Links para notícias** - CNN Brasil, GloboNews, CNN EUA, Fox News
- **Tech News** - Hacker News, TabNews, Reddit, Newsletters
- **Suas notas recentes** - Lista automática das últimas 10
- **Tarefas urgentes** - Filtro por prioridade alta
- **Projetos ativos** - Lista dos projetos em andamento
- **Estudos** - Últimos 5 arquivos de estudos
- **Atalhos rápidos** - Links diretos para ações comuns

### **2. Daily Notes Melhoradas**
- **Frase motivacional** - Diferente a cada dia
- **Tasks queries** - Funcionando automaticamente
- **Dataview** - Notas criadas hoje/ontem
- **Template simples** - Apenas o essencial

## 🚀 **Como Usar:**

### **Home Dashboard:**
1. **Abra** `00-index/Home.md`
2. **Clique nos links** para acessar notícias
3. **Use os atalhos** para navegar rapidamente
4. **Atualize** para nova frase motivacional

### **Daily Notes:**
1. **Abrir Obsidian** → Daily note abre automaticamente
2. **Use `Ctrl/Cmd + D`** para abrir manualmente
3. **Adicione tarefas** na seção "Novas Tarefas"
4. **Faça notas** na seção "Notas"

## 🔧 **Funcionalidades:**

### **Frase Motivacional:**
- Muda automaticamente a cada atualização
- 20 frases diferentes incluídas
- Pode adicionar mais no script `frase-motivacional.js`

### **Tasks Queries:**
- **Tarefas de Hoje:** `(due today) OR (scheduled today)`
- **Tarefas de Ontem:** Busca na daily anterior
- **Tarefas Urgentes:** `priority is high`

### **Dataview:**
- **Notas recentes:** Últimas 10 criadas
- **Projetos:** Lista de projetos ativos
- **Estudos:** Últimos 5 arquivos de estudos

## ⚙️ **Configuração:**

### **Plugins Necessários:**
- ✅ Templater (scripts e templates)
- ✅ Dataview (listas automáticas)
- ✅ Tasks (gerenciamento de tarefas)
- ✅ Periodic Notes (daily notes automáticas)

### **Atalhos Configurados:**
- `Ctrl/Cmd + D` - Abrir Daily Note
- `Ctrl/Cmd + Shift + P` - Command Palette
- `Ctrl/Cmd + O` - Quick Switcher

## 🎨 **Personalização:**

### **Adicionar Mais Notícias:**
1. Edite `00-index/Home.md`
2. Adicione links na seção apropriada
3. Salve e atualize

### **Adicionar Frases Motivacionais:**
1. Edite `__data__/Scripts/frase-motivacional.js`
2. Adicione frases no array `frases`
3. Salve e atualize a Home

### **Mudar Template Daily:**
1. Edite `__data__/Templates/daily-simple.md`
2. Reinicie o Obsidian

## 🔄 **Workflow Diário:**

### **Manhã:**
1. Abrir Obsidian → Home Dashboard
2. Ler frase motivacional
3. Verificar notícias importantes
4. Abrir Daily Note (`Ctrl/Cmd + D`)
5. Revisar tarefas pendentes

### **Durante o dia:**
1. Usar Daily Note para tarefas
2. Consultar Home para notícias
3. Adicionar notas e reflexões

### **Noite:**
1. Revisar o que foi feito
2. Planejar para amanhã
3. Fechar Obsidian

## 💡 **Dicas:**

- **Atualizar frase:** Recarregue a Home (Ctrl/Cmd + R)
- **Nova daily:** Use `Ctrl/Cmd + D` ou Periodic Notes
- **Buscar:** Use Quick Switcher (`Ctrl/Cmd + O`)
- **Notícias:** Clique nos links para abrir no navegador
