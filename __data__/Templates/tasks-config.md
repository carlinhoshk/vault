# 📋 Configuração do Sistema de Tasks

## 🔧 Queries Úteis para Daily Notes

### Tarefas Pendentes de Ontem
```tasks
not done
due before today
path includes "01 - Daily"
sort by due
```

### Tarefas de Hoje
```tasks
not done
due today
path includes "01 - Daily"
sort by due
```

### Tarefas Atrasadas
```tasks
not done
due before today
path includes "01 - Daily"
sort by due
```

### Tarefas Sem Data
```tasks
not done
no due date
path includes "01 - Daily"
sort by path
```

### Tarefas de Alta Prioridade
```tasks
not done
priority is high
path includes "01 - Daily"
sort by due
```

### Tarefas em Andamento
```tasks
not done
has start date
path includes "01 - Daily"
sort by start
```

## 📝 Formato de Tarefas Recomendado

### Tarefa Básica
- [ ] Tarefa simples

### Tarefa com Data
- [ ] Tarefa com prazo 📅 2025-08-25

### Tarefa com Prioridade
- [ ] Tarefa importante 🔥

### Tarefa com Data de Início
- [ ] Tarefa em andamento 🛫 2025-08-25

### Tarefa com Prazo e Início
- [ ] Tarefa complexa 🛫 2025-08-25 📅 2025-08-30

### Tarefa Recurrente
- [ ] Exercícios diários 🔁 every day

## 🎯 Tags Úteis para Organização

- `#urgente` - Tarefas que precisam ser feitas imediatamente
- `#projeto` - Tarefas relacionadas a projetos específicos
- `#estudo` - Tarefas de estudo/aprendizado
- `#saude` - Tarefas relacionadas à saúde/exercícios
- `#casa` - Tarefas domésticas
- `#trabalho` - Tarefas profissionais

## 📊 Exemplo de Daily Note Organizada

```markdown
# 🗓️ 25 de Agosto de 2025

## 🔄 Tarefas Pendentes de Ontem
```tasks
not done
due before 2025-08-25
path includes "01 - Daily"
sort by due
```

## 📌 Tarefas de Hoje
```tasks
not done
due 2025-08-25
path includes "01 - Daily"
sort by due
```

## 🎯 Novas Tarefas

### 🔥 Prioridade Alta
- [ ] Reunião importante com cliente #trabalho #urgente 📅 2025-08-25 14:00

### 📋 Prioridade Média
- [ ] Estudar C++ #estudo 🛫 2025-08-25
- [ ] Fazer exercícios #saude 🔁 every day

### 💡 Ideias/Futuro
- [ ] Implementar novo sistema de backup #projeto
```

## 🔄 Workflow Recomendado

1. **Manhã**: Revisar tarefas pendentes de ontem
2. **Planejamento**: Adicionar novas tarefas do dia
3. **Durante o dia**: Marcar tarefas como concluídas
4. **Noite**: Revisar e migrar tarefas pendentes para o próximo dia
