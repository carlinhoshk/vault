# 📚 Vault - Sistema de Produtividade Pessoal

## 🗂️ Estrutura Organizada

### 📁 Pastas Principais

- **`00-index/`** - Home Dashboard e índices principais
  - `Home.md` - Dashboard principal com notícias e atalhos
  - Outros arquivos de índice

- **`01-daily/`** - Notas diárias
  - Formato: `DD-MM-YYYY.md`
  - Template automático com frase motivacional
  - Tasks queries e Dataview funcionando

- **`03-estudos/`** - Material de estudos
  - Faculdade, cursos, livros
  - Organizado por semestre/disciplina

- **`04-projetos/`** - Projetos pessoais e profissionais
  - Rinha2025, projetos de estudo
  - Documentação e planejamento

- **`06-organizacao-linux/`** - Configurações e organização
  - Keybinds, configurações do sistema
  - Scripts e automações

- **`vida-publica/`** - Documentos públicos
  - Links da receita, documentos oficiais

### 📁 Pastas de Sistema

- **`__data__/`** - Dados do sistema
  - `Templates/` - Templates para daily notes
  - `Scripts/` - Scripts do Templater
  - `Media/` - Imagens e arquivos de mídia

- **`99-index-old/`** - Arquivos antigos preservados
  - Notas importantes do sistema anterior
  - Documentos com conteúdo significativo

- **`.obsidian/`** - Configurações do Obsidian
  - Plugins, temas, configurações

## 🚀 Funcionalidades

### 📰 Home Dashboard
- Frase motivacional diária
- Links para notícias (CNN, GloboNews, Tech)
- Tarefas urgentes
- Projetos ativos
- Estudos em andamento

### 📅 Daily Notes
- Criação automática
- Template com frase motivacional
- Tasks queries funcionando
- Herança de tarefas pendentes
- Dataview para notas criadas

### 🔧 Plugins Configurados
- **Templater** - Templates dinâmicos
- **Dataview** - Consultas automáticas
- **Tasks** - Gerenciamento de tarefas
- **Periodic Notes** - Daily notes automáticas
- **Excalidraw** - Desenhos e diagramas

## ⚡ Atalhos Úteis

- `Ctrl/Cmd + D` - Abrir Daily Note
- `Ctrl/Cmd + Shift + P` - Command Palette
- `Ctrl/Cmd + O` - Quick Switcher

## 📋 Workflow Diário

1. **Manhã** - Abrir Home Dashboard → Daily Note
2. **Durante o dia** - Adicionar tarefas e notas
3. **Noite** - Revisar e planejar próximo dia
