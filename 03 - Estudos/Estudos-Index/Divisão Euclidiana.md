# 📘 Matemática Básica: Divisão com Resto (Divisão Euclidiana)



88 ÷ 8 = 11 → resto 0     → 8 × 11 + 0 = 88
11 ÷ 8 = 1  → resto 3     → 8 × 1 + 3 = 11
1 ÷ 8  = 0  → resto 1     → 8 × 0 + 1 = 1


## 🧠 O que é?

A divisão com resto, também chamada de **divisão euclidiana**, é uma forma de dividir dois números inteiros onde:

- Um número (o dividendo) é dividido por outro (o divisor),
    
- O resultado é um **quociente** inteiro e um **resto**.
    

### 📐 Fórmula:

```
A = B × Q + R
```

Onde:

- `A` é o **dividendo**
    
- `B` é o **divisor**
    
- `Q` é o **quociente inteiro**
    
- `R` é o **resto**, com a condição: `0 ≤ R < B`
    

---

## 📊 Exemplos passo a passo

### Exemplo 1: 13 ÷ 5

1. Quantas vezes o 5 cabe dentro do 13? R: 2 vezes.
    
2. `5 × 2 = 10`
    
3. `13 - 10 = 3`
    

🔸 Resultado:

```
13 ÷ 5 = 2, resto 3
Verificação: 5 × 2 + 3 = 13
```

---

### Exemplo 2: 88 ÷ 8

1. `8 × 11 = 88`
    
2. `88 - 88 = 0`
    

🔸 Resultado:

```
88 ÷ 8 = 11, resto 0
Verificação: 8 × 11 + 0 = 88
```

---

## ❗ Por que o resto nunca é maior que o divisor?

Porque senão ainda daria pra dividir mais uma vez! O resto sempre tem que ser **menor** que o divisor:

```
Se A = B × Q + R, então 0 ≤ R < B
```

Se o resto fosse igual ou maior que o divisor, ainda dá pra aumentar o quociente.

---

## 🧩 Para que serve isso?

- Conversão entre bases (decimal para binário, octal, hexadecimal)
    
- Divisibilidade
    
- Módulo em programas de computador
    
- Criptografia
    
- Sistemas de numeração
    

---

## ✅ Dica para lembrar

- **Divida**, pegue o quociente inteiro.
    
- **Multiplique** o divisor pelo quociente.
    
- **Subtraia** do dividendo para achar o resto.
