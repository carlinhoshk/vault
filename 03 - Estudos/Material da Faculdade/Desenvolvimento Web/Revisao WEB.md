### Web 2.0
 Com a capcidade de criar e compartilhar informaões de forma dinamica integrando tecnologias de lado cliente e servidor para servir conteudos dinamicos e personalizados.

### HTML 

- HEAD Define os meta dados 
- BODY onde o conteúdo da pagina é o corpo
- H1 ate H6 define cabeçalhos de diferentes niveis
- P Define um paragrafo
- Strong define como Strong o texto ou Negrito
- EM define o texto com enfase

### Imagens de Fundo e Cores de Fundo 
Através de atributos e da utilização de CSS, é possível definir imagens e cores de fundo para diferentes elementos na página, proporcionando uma experiência visual mais rica e personalizada.

### Tabelas
A tag *table* permite a criação de tabelas em HTML, essenciais para a organização de informações em um formato tabular. 

As tags tr, th, e td são usadas para definir linhas, cabeçalhos e células de dados, respectivamente.
