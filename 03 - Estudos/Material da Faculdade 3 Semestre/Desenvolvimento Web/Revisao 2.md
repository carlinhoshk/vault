# A Internet

```
A Internet é basicamente uma coleção de computadores, todos
conectados em conjunto a uma grande rede. Sua topologia
provê um mecanismo de acesso e entrega da informação de
modo que fragmentos desta possam tomar múltiplas rotas de
um ponto a outro. Essas múltiplas rotas tornam a rede
incrivelmente robusta – se uma parte falha, a informação pode
ainda viajar por outras rotas alternativas.
```

# Informação na Internet

```
■ Pedidos por informações ou serviços
■ Respostas contendo a informação ou resultado de um
serviço
■ Respostas informativas, isto é, as razões por que o serviço
ou informação não pode ser entregue
```

# Modelo Cliente/Servidor

```
A informação é entregue em um modelo Cliente/Servidor; em
outras palavras, clientes (usuários) conectam-se a servidores
na Internet e usam seus recursos.
```

# Evolução da Internet

```
Nos primeiros dias da Internet, a maioria dos conteúdos
disponíveis eram somente em formato de texto. Os servidores
não eram capazes de entregar nada mais complexo que isso, e
as redes interconectadas não eram rápidas nem confiáveis o
suficiente para permitir a transferência de algo mais complexo
que texto puro.
```

# Primeiras Aplicações

```
■ E-mail: Revolucionou as possibilidades de comunicação,
sendo uma solução barata e assíncrona.
■ Gopher: Oferecia menus hierárquicos de informação
através de uma interface somente texto.
■ Telnet: Protocolo usado para comunicação entre cliente e
servidor, precursor do browser.
```

# Desempenho e Lag

```
Os gargalos de desempenho de rede se refletiam no tempo que
levava para realizar o download de arquivos de imagens,
documentos e software, gerando o conhecido Lag.
```

# Inovações

```
■ Hipertexto: Forma de vincular documentos em conjunto
utilizando referências.
■ HTML: Padrão aberto para troca de informações, que
fornece detalhes de como a página deve parecer.
```

# World Wide Web

```
A World Wide Web (WWW ou simplesmente Web) é uma
coleção de recursos vinculados como documentos, imagens,
vídeos, applets interativos e música, disponíveis para os
usuários da Internet.
```

# Servidores e Protocolos

```
■ HTTP: Protocolo de Transferência de Hipertexto,
utilizado para recuperação e envio de dados.
■ FTP: Protocolo de Transferência de Arquivos, usado para
transferir arquivos rapidamente.
■ MIME: Especificação para o formato de anexos de e-mail
não textos.
```

# Motores de Busca

```
Serviço baseado na Web que permite aos consumidores
localizar artefatos ou recursos na Internet como um todo,
utilizando mecanismos como Google, Yahoo, Bing, etc.
```

# Scripting no lado do Cliente

```
Programação no lado cliente trouxe a possibilidade de executar
parte do processamento necessário para a execução de ações
no browser, liberando o lado servidor de tarefas como exibição,
formatação ou animações.
```

# Programação no lado Servidor

```
Impulsiona a maior parte dos sites na Internet, desde servidores
HTTP até aplicações interativas como Facebook, YouTube,
etc., usando scripts para criar páginas dinamicamente.
```

# Razões para Script no Servidor

```
■ Scripts podem ser misturados com HTML.
■ Scripts no servidor podem acessar serviços como
autenticação e bancos de dados.
■ Scripts são interpretados, garantindo portabilidade entre
diferentes plataformas.

# Content Management Systems (CMS)

```
CMSs permitem a criação de sistemas de entrega de
documentos complexos de forma amigável, como Blogger e
WordPress, permitindo categorizar, publicar, controlar versão,
e criar menus dinâmicos.
```

forma dinâmica, o conceito de Web 2.0 cresceu, integrando
tecnologias de lado cliente e servidor para oferecer conteúdos
mais dinâmicos e personalizados.

# O que é HTML

```
■ Criada como uma linguagem de marcação, o HTML
(HyperText Markup Language) tem como objetivo ajudar
na definição da estrutura de documentos na Web.
■ A sua estrutura é baseada em elementos definidos por
tags, que formam a base para a criação de páginas web.
```

# Estrutura Básica de um Documento HTML

```
Um documento HTML tem uma estrutura padrão que deve ser
seguida, iniciando com uma declaração de tipo de documento
(<!DOCTYPE html>), seguido de uma seção<head>onde se
define metadados, e por fim a seção<body>, onde o conteúdo
da página é definido.
```

# Tags Básicas para Formatação de Fonte e Texto

```
■ <h1>até<h6>: Definem cabeçalhos de diferentes níveis
■ <p>: Define um parágrafo
■ <strong>: Define um texto com ênfase forte
■ <em>: Define um texto com ênfase
```

# Imagens de Fundo e Cores de Fundo

```
Através de atributos e da utilização de CSS, é possível definir
imagens e cores de fundo para diferentes elementos na página,
proporcionando uma experiência visual mais rica e
personalizada.
```

# Tabelas

```
■ A tag<table>permite a criação de tabelas em HTML,
essenciais para a organização de informações em um
formato tabular.
■ As tags<tr>,<th>, e<td>são usadas para definir
linhas, cabeçalhos e células de dados, respectivamente.
```

# Elementos de Formulário

```
Formulários são fundamentais para interatividade na web.
Utilizando tags como<form>,<input>,<textarea>, entre
outras, é possível criar campos de entrada, botões, e áreas de
texto para receber dados do usuário.
```

# Elementos de Desenvolvimento Web

```
É necessário prestar atenção ao equilíbrio de cores, à
programação visual da página, às fontes tipográficas utilizadas
para disponibilizar as informações, e à arquitetura do site e de
suas páginas.
```

# A Web: Uma das Mais Úteis Ferramentas

```
A web é uma das mais úteis ferramentas já desenvolvidas pelo
homem. Antes dela já nos comunicávamos via internet, e
muito desenvolvimento teve que ocorrer para que as coisas
fossem “fáceis” como são nos dias de hoje.
```

# Importância do Estudo

```
Para iniciarmos nossos estudos sobre Web Design, é
importante fazermos uma rápida passagem pelo caminho que
percorremos até chegarmos ao ponto em que estamos.
```

# Um Breve Histórico

```
A internet não é nada nova: como afirma Ryan (2010), ela foi
implementada pela primeira vez, como conceito, na segunda
metade da década de 1960, pelas forças armadas dos EUA,
que temiam ataques nucleares por parte dos soviéticos durante
a Guerra Fria.
```

# Desenvolvimento Inicial

```
Os militares publicaram seus estudos e despertaram o interesse
das universidades norte-americanas, que rapidamente se
interessaram por desenvolver os protocolos de comunicação
nascentes para interligar seus computadores e centros de
pesquisa. Já no início da década de 1970 vários dos protocolos
de acesso remoto e compartilhamento de arquivos da internet
estavam em pleno funcionamento: FTP, Telnet e SMTP eram
os principais deles (RYAN, 2010).
```

# Crescimento da Internet

```
Durante mais de duas décadas, a Internet cresceu e floresceu
como ferramenta de comunicação entre entidades de ensino e
empresas de tecnologia. Contudo, o acesso do grande público
a este crescente manancial de informações ainda não havia
acontecido.
```

# Nascimento da Web

```
Essa situação mudaria em 1989, quando Tim Berners-Lee
criou o protocolo HTTP e a linguagem HTML. Era o
nascimento da World Wide Web e o início da massificação da
internet (RYAN, 2010).
```

# Foco no Usuário

```
Diferentemente das primeiras duas décadas da internet, o foco
nos dias de hoje é o usuário. Em 2015, ultrapassamos 3,1
bilhões de usuários da web, e já ultrapassamos 1 bilhão de
sites ativos (Internet Live Stats, 2016).
```

# Desafios Atuais

```
A enorme quantidade de sites disponíveis gera um problema
para quem deseja disponibilizar informações por meio da web:
há escolhas demais para o usuário, e a quantidade de escolhas
só faz crescer a cada dia.
```

# Sucesso dos Sites

```
Segundo Travis (2013), a tecnologia nos permite inúmeras
formas de apresentar o conteúdo, mas nem sempre os sites
mais “tecnológicos” são os que fazem mais sucesso. Faz mais
sucesso aquele site que põe a experiência do usuário em
primeiro lugar.
```

# Padronização da Experiência do Usuário

```
No início da década de 2000, a ISO publicou a família ISO
9241, que se preocupa em padronizar a experiência do usuário
com os sistemas com os quais interage. Em especial, a
ISO/NBR 9241-11, que leva o título de “Requisitos
Ergonômicos para Trabalho de Escritórios com Computadores
Parte 11 – Orientações sobre Usabilidade”.
```

# Princípios de Usabilidade

```
A ISO/NBR 9241 postula três princípios de usabilidade (ABNT, 2000):
```
1. Foco no Usuário
O foco do processo deve ser o usuário e as tarefas que ele precisa
desempenhar, e este foco deve começar cedo e ser contínuo.
2. Mensuração Empírica
O comportamento do usuário deve ser mensurado empiricamente ao
longo de todo o processo.
3. Processo Iterativo
O design é um processo iterativo, isto é, deve seguir um fluxo de
implementação, mensuração e correção, repetindo-se estes três estágios
até que os resultados esperados sejam atingidos.


# Princípios de Usabilidade

```
O objetivo primordial dos três princípios de usabilidade é
maximizar a usabilidade do website em desenvolvimento.
Hartson e Pyla (2012) definem usabilidade como o conjunto
de componentes mais pragmáticos da experiência do usuário,
composto por elementos observáveis e constatáveis:
■ Eficiência
■ Produtividade
■ Facilidade de uso
■ Facilidade de aprendizado
■ Facilidade de retenção do conteúdo aprendido
■ Satisfação do usuário
```

# Importância das Cores

```
Alguns aspectos de usabilidade levantados por Hartson e Pyla
(2012) são objetivamente mensuráveis, enquanto outros são
mais subjetivos. Miller (2011) cita as cores como sendo o
elemento mais poderoso para “guiar, direcionar e persuadir o
usuário”.
```

# Perspectiva Emocional do Design

```
O esquema de cores em um website se encaixa naquilo que
Hartson e Pyla (2012) definem como “a perspectiva emocional
do design”. Esta se refere ao impacto emocional do design,
bem como aos aspectos que dependem dos valores pessoais,
culturais e sociais.
```

# Respostas Psicológicas às Cores

```
Bleicher (2012) explica que as respostas psicológicas às cores
são de duas naturezas:
■ Respostas Inatas– São efeitos da evolução e da seleção
natural. Por exemplo, a combinação de amarelo e preto
sinaliza perigo e nos põe em alerta.
■ Respostas Aprendidas– São dependentes da cultura
em que nos inserimos. Por exemplo, na cultura ocidental,
azul é uma cor ligada ao gênero masculino, enquanto rosa
é ligada ao gênero feminino.
```

# Significado das Cores

```
Entender o significado das cores e as respostas psicológicas
que provocam no indivíduo é fundamental para todo bom
designer de websites.
```

# Classificação de Fontes

```
As fontes tipográficas diferem enormemente umas das outras. Santa
Maria (2014) sugere a classificação mais utilizada entre os tipógrafos:
■ Sem Serifa (ou fontes não serifadas) – fontes sem apêndices nas
extremidades dos caracteres;
■ Com Serifa (ou serifadas) – fontes com apêndices levemente curvos
ou angulados nas extremidades dos caracteres;
■ Com Serifa Reta ou Retangular (do inglês slab serif) – fontes com
apêndices retos nas extremidades dos caracteres;
■ Cursivas (do inglês script) – fontes que imitam a escrita à mão;
■ Letras Negras (do inglês Blackletter) – fontes em estilo gótico
antigo, incidentalmente, as mais antigas fontes tipográficas de que
se tem notícia.
```

# Regras de Utilização de Fontes

```
Quando um designer se depara com essa imensidão de opções,
é natural que pergunte "Quais são as regras de uso de
fontes?". Santa Maria (2014) responde: “não existem regras
em tipografia.” Há princípios, melhores práticas e métodos que
funcionam na maior parte do tempo, mas não existe algo que
funcione o tempo todo.
```

oferecem.

Indicadas para textos curtos, frases isoladas e títulos.

# Uso de Imagens e Vídeos

```
Miller (2011) afirma que os usuários não leem detalhadamente
uma página, mas sim dão uma “passada d’olhos” pelas
páginas. Vale a máxima de que “uma imagem bem escolhida e
usada no contexto correto vale mais do que mil palavras”.
```

# Considerações sobre Imagens e Vídeos

```
Para imagens e vídeos, alguns elementos devem ser observados (MILLER,
2011):
■ Escala– A variação de tamanho dos elementos gráficos é uma
forma de adicionar “dramaticidade” às páginas.
■ Profundidade– Imagens em perspectiva dão a impressão de que a
página parece ter profundidade, parecendo ser um elemento
tridimensional.
■ Animação– Elementos gráficos animados podem criar uma
dimensão extra de informações.
■ Som– O som acompanhando as imagens caiu em desuso, e usar
este artifício automaticamente na carga da página é um erro grave.
■ Variabilidade– A variação de elementos gráficos pode adicionar ou
confundir a experiência do usuário.
```

# O Que é Responsividade

```
Segundo Sharkie e Fisher (2013), responsividade é a
capacidade de um website de se adaptar a qualquer
dispositivo, em qualquer dimensão de tela e resolução, com
qualquer tipo de interface de interação, apresentando as
informações de forma coerente e agradável.
```

# Desafios da Responsividade

```
A variedade de dispositivos no mercado com tamanhos de tela,
resoluções e tipos de interface diferentes impõe dificuldades
aos desenvolvedores de websites. Comparações entre
computadores desktop, laptops, tablets e smartphones ilustram
essas variações.
```

# Características Necessárias

```
Para que um website tenha responsividade, algumas
características devem estar presentes:
■ Identificação do Dispositivo e do Navegador– O
servidor deve identificar todas as características relevantes
de hardware e software do dispositivo.
■ Formatos de Página Flexíveis– Devem ser adaptáveis
a qualquer dimensão e resolução de tela, dispondo os
elementos da forma mais racional para cada dispositivo.
■ Tamanhos Alternativos para Elementos Gráficos–
Tamanhos diferentes podem afetar os tempos de carga da
página.
```

# Características Necessárias

```
Para que um website tenha responsividade, algumas
características devem estar presentes:
■ Formulários Flexíveis– Formulários estáticos geram
dificuldades de leitura em telas pequenas.
■ Elementos Textuais Flexíveis– Tamanhos de fonte
devem variar de acordo com o tamanho da tela.
```
